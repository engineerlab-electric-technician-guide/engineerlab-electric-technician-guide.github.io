전기기능사 필기, 개념과 문제를 어떻게 연결할까

전기기능사 필기는 문제를 많이 푸는 것만으로 시작하기보다 용어·단위·회로의 기본 관계를 먼저 이해하고, 문제에서 막힌 개념을 다시 확인하는 순환으로 공부하세요. 처음에는 정답률보다 왜 틀렸는지를 구분하는 일이 중요합니다.

기초를 지나치지 않는 3단계

  1. 낯선 표현 표시: 문제를 풀다가 의미를 설명하지 못하는 용어와 단위를 따로 적습니다.
  2. 개념으로 되돌아가기: 해설의 공식만 외우지 말고 어떤 조건에서 적용되는지 확인합니다.
  3. 유형 재확인: 같은 유형을 다시 풀고 오답 이유가 사라졌는지 기록합니다.

오답 노트는 짧게

오답을 전부 베껴 쓰면 복습할 분량만 늘어납니다. 틀린 이유를 ‘용어 미이해’, ‘조건 누락’, ‘계산 과정’, ‘시간 부족’ 중 하나로 분류하고, 다음에 확인할 개념 한 줄만 적어보세요. 맞힌 문제도 우연히 찍었다면 다시 확인할 항목으로 남깁니다.

주간 점검 질문

  • 설명 없이 공식을 외운 문제는 없는가?
  • 지난주 오답 중 같은 이유로 다시 틀린 문제가 있는가?
  • 문제 풀이 시간 때문에 놓친 문항과 개념 부족 문항을 구분했는가?

시험 범위는 공식 출제 기준에 맞춰 확인하세요. 필기 계획과 별개로 실기 연습 환경도 일찍 살펴보는 편이 좋습니다.
